# Studio

Studio is a short-form video production project focused initially on YouTube Shorts: original narrated short stories over Minecraft parkour gameplay with synchronized captions. TikTok may be added later.

## Workflow

Director → Researcher → Reviewer → Strategist → Scriptwriter → Producer → Reviewer → Publishing (with owner's approval) → Analytics.

## Current phase

Competitor and trend research for Minecraft parkour storytelling Shorts. Story categories remain open to evidence-based research.

## Automation diagnostics

GitHub pull request activity may be used for a controlled test of ChatGPT Work event-triggered tasks. Test pull requests are diagnostic only and must not publish content.
